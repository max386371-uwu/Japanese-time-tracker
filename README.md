# Language Study Tracker

A free, privacy-focused language study time tracker for language learners.

Track your study time, projects, goals, and progress with a modern, customizable interface. Designed to work offline first, with optional cloud sync, a companion website, and social features planned for future releases.

> **Current Status:** v0.1 Alpha (Japanese-only)

## Features

### Study Timer
- Track study sessions with a simple timer.
- Resume recent projects.

### Dashboard
- Daily, weekly, monthly, yearly, and all-time statistics.
- Language cards.
- Streak tracking.
- Activity summaries.

### Projects
- Organize study into projects.
- Categories and tags.
- Quick access to recent projects.

### Reports
- Pie charts and graphs.
- Time breakdowns.
- Study statistics.

### Customization
- Multiple themes.
- Customizable interface.

### Backup
- Local-first storage.
- Import and export backups(.json)
-To and from Toggl, as CSV.
